# Сайт учёта волонтёрских часов — дизайн

## Зачем
Ученики школы (NIS Ukk) сами записывают, сколько часов волонтёрства сделали. Админ проверяет и подтверждает часы. Регистрация открыта только ученикам из школьного списка.

## Цели
- Ученик регистрируется только если его ФИО/email есть в списке.
- Ученик вносит запись о волонтёрстве: период (дата начала и конца), описание, количество часов.
- Админ видит все записи, подтверждает или отклоняет их с комментарием.
- Ученик видит сумму подтверждённых часов.

## Не цели
- Загрузка справок и файлов (не нужно в первой версии).
- Публичная страница с данными учеников.
- Открытая регистрация для не-учеников.

## Антицели
- Хранить ИИН (колонка «Логин» из списка) или любые лишние персональные данные.
- Дать ученику менять подтверждённые часы.

## Ограничения
- Хостинг: Render (web service + Render Postgres).
- Список учеников — из файла «Оқушылар тізімі.xlsx». Импортируются только Класс, ФИО, Email.

## Подход (выбран)
- **Backend:** Python + Flask.
- **База:** PostgreSQL на Render.
- **Вход ученика:** email из списка → одноразовый 6-значный код на школьную почту → сессия. Пароля нет.
- **Вход админа:** отдельный аккаунт, логин и пароль (хэш bcrypt). Создаётся командой при первом запуске.
- **Письма:** отправка через SMTP (нужен почтовый ящик с паролем приложения).

## Модель данных
- `students`: id, full_name, class_name, email (unique). Заполняется импортом.
- `admins`: id, login (unique), password_hash.
- `volunteer_entries`: id, student_id, date_start, date_end, description, hours (decimal), status (`pending` / `approved` / `rejected`), admin_comment, created_at, decided_at.
- `login_codes`: id, email, code_hash, expires_at, used.

## Экраны
1. Вход ученика: ввод email → код → вход.
2. Кабинет ученика: сумма подтверждённых часов, список записей со статусами, форма «добавить запись».
3. Вход админа.
4. Админ: список записей со статусом `pending`, кнопки «подтвердить» / «отклонить» с комментарием, фильтр по классу.

## Правила
- Часы: от 0.5 до 200 за одну запись, шаг 0.5. В интерфейсе поле называется «Часы».
- Период: дата начала ≤ дата конца ≤ сегодня. Часы — сумма за весь период.
- Ученик может редактировать и удалять только записи со статусом `pending`.
- Подтверждённая запись не меняется ни учеником, ни админом.

## Что осталось на ваше решение
1. Почтовый ящик для отправки кодов (Gmail с паролем приложения или другой SMTP). Без него вход работать не будет.
2. Кто будет админом (логин/почта), чтобы создать аккаунт.

## Мои решения (можно поменять)
- Коды действуют 10 минут, попыток ввода 5.
- Импорт списка — отдельная команда, а не загрузка через сайт.
- Язык интерфейса: русский, с казахскими ФИО как есть.
